# 대본에 맞춰서 TTS 제작 · Voice Studio

대본 입력 → OAuth로 GPT-6.1 Sol 또는 Claude 감정 분석 → 사용자의 태그 검수 → Gemini 3.8 Flash TTS 음성 생성 프로그램입니다. 별도 패키지 설치 없이 Node.js 22 이상과 Mac에 설치된 공식 Codex CLI(GPT) 또는 Claude Code(Claude)를 사용합니다.

## 실행

- 이 폴더의 **시작.command**를 더블 클릭합니다. 로컬 브라우저 화면이 열립니다. 실행 창을 닫으면 서버가 종료됩니다.
- 빌드된 앱은 **dist/Voice Studio.app**입니다. 실행하면 브라우저가 열립니다. 앱은 이 폴더의 `data`에 작업을 저장하므로 폴더 전체를 유지하세요.
- 개발 실행: `npm start`. 테스트: `npm test`. 다시 빌드: `npm run build`.
- 기본 주소는 `http://127.0.0.1:4319`입니다. 포트가 사용 중이면 다음 포트를 사용합니다. `TTS_PORT`로 변경할 수 있습니다.

## 사용 순서

1. **연결 및 목소리 설정**에서 ChatGPT·Claude 연결과 Gemini 키를 확인합니다. GPT는 이 Mac의 공식 Codex CLI에 저장된 ChatGPT OAuth 인증을, Claude는 Claude Code(Claude 앱에 포함된 CLI 포함)에 저장된 Claude 구독 OAuth 인증을 사용합니다. 미로그인 상태에서는 **ChatGPT OAuth 로그인** 또는 **Claude OAuth 로그인**을 누릅니다. OpenAI·Anthropic API 키는 필요하지 않습니다. 둘 중 하나만 연결해도 됩니다.
2. Gemini 키는 `GEMINI_API_KEY` / `GOOGLE_API_KEY` 환경 변수, 앱에 저장한 비공개 키 파일, 제공하신 `API key.rtf` 순서로 불러옵니다. `AQ.` 형식의 최신 인증 키도 지원합니다. 키 값은 화면·로그·내보내기에 표시하지 않습니다.
3. 기본 목소리를 고릅니다. 가장 안정적인 전용 음색을 원하면 **전용 목소리 한 번 만들기**로 목소리를 생성하고, 미리 듣고 **설정 저장**을 누릅니다. 이후 같은 `voice_…` ID를 재사용합니다. Google AI Studio에서 만든 음성 ID를 직접 입력해도 됩니다.
4. **새 음성 작업**에서 대본을 붙여 넣거나 UTF-8 `.txt` 파일을 가져옵니다. 연출 메모를 선택적으로 적고 **감정 태그 만들기**를 누릅니다.
5. **Gemini 프롬프트 검수**의 큰 텍스트 박스에서 실제로 전달될 연출 지시와 읽을 대본 전체를 확인합니다. **연출 지시 수정**을 열면 구간별 텍스트 박스에서 어투를 바꾸고 앞뒤 호흡·쉼을 조절할 수 있습니다. 수정 내용과 읽기 속도는 위 프롬프트에 바로 반영됩니다. **원문은 읽기 전용**입니다. 목소리도 함께 확인합니다.
6. 검수 확인란을 체크하고 **검수 완료**를 누릅니다. 이후 **음성 생성**을 누르면 실제 Gemini API를 호출합니다.
7. 완성된 WAV를 재생하고 다운로드합니다. 감정 태그 대본, 원문, 검수 기록 JSON, 개별 생성 구간도 보관됩니다.

감정 분석 AI는 설정의 **기본 AI**로 정하고, 작업마다 대본 화면의 **감정 분석 AI**에서 GPT 또는 Claude로 바꿀 수 있습니다. Claude 기본 모델은 `claude-opus-5-5`이며 모델 ID나 `opus`·`sonnet` 별칭으로 바꿀 수 있습니다. 분석 AI는 음성 결과에 영향을 주지 않아 검수 승인 해시에 포함되지 않으므로, AI를 바꿔도 승인된 검수본은 유지됩니다. 새 GPT 모델은 설정의 **감정 분석 모델 ID**를 변경하면 새 작업부터 적용됩니다. 감정 분석은 기본 `high` 추론 수준입니다. 생성 중인 작업은 승인 당시 설정을 사용합니다. 현재 작업의 목소리·속도·태그를 바꾸면 다시 검수 완료해야 합니다.

**영상 장르 템플릿:** 감정 분석 프롬프트는 장르 연출 지침(템플릿)과 고정 규칙으로 구성됩니다. 대본 화면의 **영상 장르 템플릿**에서 썰·스토리텔링 / 공포·미스터리 / 코미디·예능 / 정보·지식 해설 / 감동·힐링 / 이슈·시사 정리 중 고르거나 직접 만든 템플릿을 선택합니다. **프롬프트 보기 · 수정**에서 지침을 수정해 저장하거나, 새 템플릿으로 저장하거나, 직접 만든 템플릿을 삭제할 수 있습니다. 기본 템플릿은 수정 후 **기본값 복원**으로 되돌릴 수 있습니다. **실제로 전달되는 전체 분석 프롬프트 보기**에서는 저장하지 않은 수정까지 반영해 고정 규칙·연기 강도·대본이 포함된 최종 프롬프트를 확인할 수 있습니다(모델 호출 없음). 원문 보존·출력 형식·Gemini 3.8 TTS 규칙은 품질과 안전을 위해 항상 함께 전달되며 템플릿보다 우선합니다. 템플릿은 `data/templates.json`에 저장되고, 분석할 때 사용한 템플릿 내용은 작업에 함께 기록됩니다. 템플릿은 분석에만 쓰이므로 바꿔도 검수 승인은 유지됩니다. 설정에서 새 작업의 기본 템플릿을 정할 수 있습니다.

## 원문 보존 방식

GPT는 대본을 다시 출력하지 않고 고정된 구간 ID별 감정·어투 정보만 반환합니다. 서버는 원문 문자열을 직접 나누고 연결하며, 공백·줄바꿈·문장부호·분해형 한글까지 완전 일치와 SHA-256을 검사합니다. 모델이 원문 필드를 추가하거나 태그 구간을 누락·재배열하면 결과를 거부합니다. 붙여넣기는 브라우저가 입력한 문자열을 기준으로 보존합니다. 파일 불러오기는 원본 문자열을 별도로 유지하므로 CRLF도 보존됩니다. 한 작업은 60,000자 이내입니다.

화면과 태그 대본의 `⟦따뜻함 · warm and reassuring⟧` 같은 표시는 검수용입니다. **실제 요청에는 그 표시를 넣지 않습니다.** 영어 어투는 `parts[].speech_metadata.style`, 원문은 `parts[].text`로 분리됩니다. 사용자가 검수한 `<breath>`, `<short pause>` 같은 순간 호흡 태그만 원문 주변에 삽입됩니다. 기존 `<…>` 표기는 Gemini가 음성 이벤트로 해석할 수 있어 원문을 임의 변경하지 않고 입력을 거부합니다.

검수 텍스트 박스의 `[연출 지시]`, `[읽을 대본]`, 구간 번호는 이 실제 요청을 쉽게 읽도록 붙인 제목이며 음성에 포함되지 않습니다. 미리보기는 음성 생성과 같은 원문 보존·공백 병합·속도 지시·구간 분할·API 요청 구성 함수를 사용합니다. 미리보기 확인에는 Gemini 호출이나 과금이 없고, 저장하지 않은 연출 변경도 확인할 수 있습니다. 입력 내용이 잘못되어 미리보기를 만들 수 없으면 저장·검수 완료·음성 생성이 차단됩니다.

검수 승인은 원문 해시, 전체 태그, 음성 ID, 모델 ID, 속도, 구간 길이와 요청 구성 방식의 버전에 묶입니다. 요청 구성 방식이 개선되면 이전 승인은 무효가 되므로 바뀐 프롬프트를 다시 확인하고 검수 완료해야 합니다. 미승인 요청과 변경된 검수본의 생성은 서버에서 차단합니다. 프로그램이 전송하는 원문 보존을 검사하는 것이며, 생성 모델이 실제로 모든 음절을 읽었는지 자동 음성 인식으로 보장하는 기능은 포함하지 않습니다. 완성 음성을 재생해 최종 확인하세요.

빈 줄이나 공백만 있는 구간은 Gemini가 빈 입력으로 거부할 수 있으므로, 음성 요청을 만들 때 인접 문장에 합칩니다. 공백·줄바꿈과 검수한 호흡 태그의 순서는 그대로 보존하며, 저장된 원문·구간·감정 태그·검수 승인은 변경하지 않습니다. 비어 있는 어투는 선택적 API 메타데이터에서 생략합니다. 기존 작업도 대본이나 감정 분석을 다시 만들 필요 없이 재시도할 수 있습니다.

## 공식 문서에 따른 음질·일관성 설정

- **모델:** `gemini-3.8-flash-tts`. 공식 문서는 높은 음질, 섬세한 연기, 장문 음색 안정성을 위한 모델로 설명합니다.
- **음색:** 고정 `voiceConfig.voice`. 기본 제공 음성과 영구 저장된 `voice_…` ID를 지원합니다. 전용 음색은 생성 때마다 만들지 않습니다. 저장 음성은 마지막 사용으로부터 1년 동안 유지되고 사용 시 유지 기간이 갱신됩니다.
- **연출:** 유튜브 스토리텔링 기준입니다. 분석 AI는 대본을 훅·빌드업·클라이맥스·반전·리액션·마무리 같은 비트로 나누고, 비트마다 들리는 전달(감정·에너지·음높이 변화·음량·숨결)을 구체적인 영어 지시로 씁니다. 감정이 고조되면 지시도 함께 고조시키고, 반전 전후는 분명히 대비시키며, 인용 대사는 인물의 감정으로 연기합니다. `calm`, `matter-of-fact`처럼 아나운서 톤을 만드는 단어는 의도된 대비에만 씁니다. 같은 비트 안에서는 같은 문자열을 재사용하고, 연속된 같은 style은 하나의 `parts[]`로 합쳐 문장 경계에서 억양이 끊기지 않게 합니다(생성 구간 길이는 넘기지 않음). 검수 화면에 연출 종류와 전환 횟수가 표시됩니다. 성별·나이·고정 억양·음색·화자 이름과 “동일 음색을 유지하라” 같은 지시는 가이드가 드리프트 원인으로 지적하므로 넣지 않습니다.
- **연기 강도:** 생동감 있게(기본, 유튜브용) / 과감하게 / 차분하게. 모든 구간의 style 뒤에 같은 짧은 문구(`animated and expressive` / `highly animated, vivid and emphatic` / 없음)를 붙이고, 분석 AI의 연출 세기도 함께 조절합니다. 작업마다 검수 화면에서 바꿀 수 있으며, 바꾸면 다시 검수 완료해야 합니다.
- **호흡·리액션:** 가이드 권장 태그 중 `<short pause>`, `<long pause>`, `<breath>`, `<gasp>`, `<sigh>`, `<exhales>`, `<laugh>`, `<chuckle>`, `<giggle>`, `<tsk>`를 구간 앞뒤에 넣을 수 있습니다. 분석 AI는 놀람·웃음·한숨 같은 리액션을 가장 강한 순간에만 배치합니다(짧은 영상 기준 3–8개). 대사 추가와 효과음 태그는 생성하지 않고, 문장부호·줄바꿈이 이미 쉼을 만드는 곳에는 쉼 태그를 겹쳐 넣지 않습니다.
- **속도:** 자연스럽게 / 여유 있게 / 경쾌하게. style에 가이드 표현(`speaking slowly` / `speaking rapidly`)을 추가하며 숫자 배속 파라미터를 임의로 만들어 보내지 않습니다.
- **포맷:** `responseModalities: ["AUDIO"]`, `responseFormat.audio: { mimeType: "AUDIO_WAV", sampleRate: 24000 }`. 원본 24kHz·모노·16bit PCM WAV를 사용합니다. 손실 압축이나 불필요한 업샘플링을 하지 않습니다. 음량을 임의로 바꾸지 않습니다.
- **긴 대본:** 문장 단위 메타데이터를 한 요청에 여러 part로 묶습니다. 기본 약 1,400자 단위로 API 입력/오디오 출력 한도에 여유를 둡니다. 출력이 잘리면 실패로 처리합니다. 장문은 동일 음성 ID로 순차 생성합니다. 별도 요청 사이의 미세한 연기·쉼 차이는 있을 수 있습니다.
- **WAV 처리:** 3.8의 단일 요청은 이미 WAV 헤더를 포함합니다. 헤더를 다시 붙이지 않고 RIFF 청크를 읽어 PCM 샘플을 합친 다음 하나의 WAV로 저장합니다. 자동 무음 제거·크로스페이드는 하지 않아 대본의 시작·끝 음절을 잘라내지 않습니다.
- **복구:** 완성된 구간을 요청 내용의 해시로 캐시합니다. 실패·취소 후 동일 검수본을 다시 생성하면 성공한 구간을 재사용합니다. 같은 결과를 다시 불러올 때 새 비용 없이 캐시를 사용합니다. 429/일시적 서버 오류만 최대 두 번 재시도하며 네트워크 타임아웃과 음성 설계 생성은 자동 재시도하지 않습니다.

음색과 연출은 생성 모델 특성상 매번 완전히 동일한 파형을 보장하지 않습니다. 같은 저장 음성 ID와 간결한 지시를 사용해 동일 화자 정체성을 유지하는 데 초점을 맞춥니다. 이미 완성된 같은 검수본은 캐시 재생으로 동일 파형을 제공합니다.

## 저장과 연결

`data/projects`에는 원문, 태그, 승인 상태와 출력이 저장됩니다. `data/audio-cache`는 완성된 구간, `data/voice-previews`는 전용 음성 샘플입니다. 앱에 입력한 키는 접근 권한 600인 `data/secrets.json`에 저장합니다. 폴더를 공유할 때 개인 대본·API 키·data를 함께 공유하지 마세요. 빌드는 비밀 파일과 대본을 앱 번들에 포함하지 않습니다.

서버는 이 Mac의 `127.0.0.1`에서만 실행됩니다. 외부 Origin과 다른 Host의 요청을 거부하며, API 변경 요청에는 앱 전용 헤더가 필요합니다. OAuth 토큰을 읽거나 복사하지 않고 공식 CLI에 인증·갱신을 맡깁니다. API 키 환경 변수(OpenAI·Anthropic·Gemini 등)는 분석 하위 프로세스에서 제거하며, Claude 분석은 도구·사용자 설정·MCP·스킬 없이 빈 임시 폴더에서 실행합니다. 요청한 대본은 감정 분석 시 선택한 AI(OpenAI 또는 Anthropic), 음성 생성 시 Google로 전송됩니다. ChatGPT·Claude 사용량 제한과 Gemini 결제·할당량이 적용됩니다.
